# Kalkulator BMI - JavaFX

Aplikasi desktop sederhana untuk menghitung Indeks Massa Tubuh yang dibangun menggunakan **apache NetBeans (JavaFX)**, dan **sceneBuilder**.

## Fitur
* Input Berat Badan (kg) dan Tinggi Badan (cm)
* Perhitungan nilai BMI otomatis
* Penentuan kategori status gizi (Kurus, Normal, Overweight, Obesitas)
* Handling error jika input bukan berupa angka

## Teknologi yang Digunakan
* **apache NetBeans (JavaFX)**
* **SceneBuilder**

## Demo aplikasi

1. Buka Aplikasi
* Jalankan aplikasi Kalkulator BMI di perangkat Anda.

2. Masukkan Berat Badan

* Ketikkan berat badan Anda saat ini pada kolom Berat Badan.

* Satuan: Gunakan satuan Kilogram (kg).

3. Masukkan Tinggi Badan

* Ketikkan tinggi badan Anda pada kolom Tinggi Badan.

* Satuan: Gunakan satuan Sentimeter (cm).

4. Tekan Tombol Hitung

5. Lihat Hasil Perhitungan
